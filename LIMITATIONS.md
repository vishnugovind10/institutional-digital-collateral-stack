# Limitations

This repository is a reference architecture and executable research implementation.

It uses synthetic data only. It does not use real collateral, real custody connections, real money movement, production keys, private APIs, live bank infrastructure, market data feeds, or customer data.

It does not provide:

- production custody
- regulated settlement
- legal finality
- bank integration
- guaranteed liquidity
- investment advice
- regulatory advice
- audit opinion
- production operational resilience

## Finality distinctions

Technical finality means the local reference state machine reached a terminal technical state.

Economic finality means the synthetic DvP scenario has completed under the local model.

Legal finality depends on law, venue rules, contracts, and jurisdiction. This repository does not model or certify legal finality.
