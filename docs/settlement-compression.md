# Settlement Compression

The compression experiment compares synthetic settlement windows:

```text
30D -> 10D -> T+2 -> T+1 -> T+0 -> Intraday -> Continuous
```

Run:

```bash
python -m digital_collateral.experiments.compression
```

## Evidence, assumptions, and results

Evidence means external public material describing industry pressure toward shorter settlement cycles and more automated settlement. The repository references that material only as context.

Model assumptions are synthetic values for obligations, available liquidity, automation, authorization validity, and settlement windows.

Simulation results are the deterministic outputs generated by this repository.

## Binding constraints

As settlement windows compress, the model shifts stress from delayed evidence collection to reconciliation discipline and then to temporal liquidity. The point is not to forecast market-wide failure rates. The point is to make a systems property visible: faster settlement changes the location of operational risk.
