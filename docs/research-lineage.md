# Research Lineage

This repository interprets public collateral-mobility research through an executable architecture lens.

The public Citi research page, "Digital Collateral: A Practical Reality", is used as institutional problem framing. The implementation is independent and does not imply endorsement, collaboration, deployment, or access to private systems.

The local source repositories provide narrower component references. This repository adds the integration thesis: continuous collateral mobility requires coordinated eligibility, valuation, custody, settlement, temporal liquidity, synchronization, reconciliation, and evidence.
